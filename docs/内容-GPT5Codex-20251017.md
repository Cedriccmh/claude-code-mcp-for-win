# Claude Code MCP 项目总结

## 项目概览
- 该仓库实现了一个 Model Context Protocol (MCP) 服务器，用于调用 Claude Code CLI，并自动附带 `--dangerously-skip-permissions` 以绕过交互式权限确认。
- 服务器通过单一工具 `claude_code` 暴露能力，可在 Cursor、Windsurf、Claude Desktop 等 MCP 客户端中统一使用，让大语言模型具备直接的文件、代码、终端与 Git 操作能力。
- 当前版本为 `1.10.12`，作者 Peter Steinberger，遵循 MIT 许可证。

## 核心功能
- **工具注册**：`setupToolHandlers()` 将 `claude_code` 工具注册到 MCP 服务器，并提供详细描述、输入模式与使用提示。
- **命令执行**：`spawnAsync()` 调用 Claude CLI，并在首次使用时输出服务器版本与启动时间，返回标准输出作为响应。
- **工作目录处理**：默认使用当前用户主目录，可通过 `workFolder` 参数指定绝对路径；若目录不存在则降级至默认路径，确保调用安全。
- **调试与容错**：`MCP_CLAUDE_DEBUG` 启用调试日志；对 CLI 缺失、超时或失败统一抛出结构化 `McpError`，同时保留 stderr/stdout 以便排查。
- **CLI 路径解析**：`findClaudeCli()` 支持 `CLAUDE_CLI_NAME` 环境变量；优先检测 `~/.claude/local/claude`，否则回退到 PATH 查找并打印警告。

## 代码结构
- `src/server.ts`：服务器主体，包含工具注册、调用处理、日志函数及 CLI 查找逻辑。
- `src/__tests__`：使用 Vitest 编写的端到端、边界与错误处理测试，依赖 mock Claude CLI (`utils/claude-mock.ts`, `persistent-mock.ts`) 及 `MCPTestClient`。
- `scripts/`：提供 `test-release.sh`, `publish-release.sh`, `restore-config.sh` 等脚本，用于本地验证与自动化发布。
- `docs/`：包含本地安装、端到端测试、发布检查表等补充文档。
- `start.sh` / `start.bat`：跨平台启动脚本，优先运行 `dist/server.js`，若无则使用 `tsx` 直接执行 TypeScript 源码。

## 安装与使用
- **运行要求**：Node.js ≥ 20；需提前安装并登录 Claude CLI，手动执行 `claude --dangerously-skip-permissions` 接受条款。
- **客户端配置**：在 `mcp.json` 或 `mcp_config.json` 中登记 `claude_code`，常用命令为 `npx @steipete/claude-code-mcp@latest`，可通过 `env` 设置 CLI 路径及调试开关。
- **本地开发**：执行 `npm install` 后可使用 `npm run dev` 或 `start.sh`；亦可借助 `npm link` 将本地构建映射为全局命令，供 MCP 客户端引用。

## 测试体系
- **测试脚本**：提供 `npm test`, `npm run test:unit`, `npm run test:e2e`, `npm run test:e2e:local`, `npm run test:coverage` 等命令。
- **Mock 机制**：测试过程中在 `~/.claude/local/claude` 下部署模拟 CLI，自动清理避免污染真实环境；真实 CLI 集成测试默认跳过。
- **调试支持**：设置 `MCP_CLAUDE_DEBUG=true` 可输出详细日志，便于定位问题；`MCPTestClient` 封装工具调用请求、超时与响应解析。

## 发布与版本管理
- **版本同步**：发布需同步更新 `package.json` 与 `src/server.ts` 的版本号，并在 `CHANGELOG.md` 中记录更新内容。
- **自动化脚本**：`publish-release.sh` 负责检查分支状态、运行测试、版本递增、生成 tag、推送仓库、创建 GitHub Release，并最终执行 `npm publish`。
- **测试发布**：`test-release.sh` 面向 macOS，支持构建、测试、切换 Claude 配置及日志监控，便于上线前验证。
- **语义化版本**：遵循 Keep a Changelog 与 SemVer；近期版本重点围绕 CLI 覆盖、构建策略与错误处理完善。
